# Naval Fleet Dashboard

A React-based command dashboard for the Naval Fleet Risk Monitoring and
Decision Support System.

## Overview
The dashboard visualizes fleet-level risk assessment and alert decisions
generated by the Spring Boot backend. It is designed to resemble a naval
command-center interface, focusing on clarity and rapid decision-making.

## Features
- Real-time fleet statistics (total, high-risk, low-risk ships)
- Color-coded alert levels (CRITICAL / WARNING / NORMAL)
- AI-driven command recommendations
- Clean and minimal command dashboard UI

## Technology Stack
- React (Frontend)
- JavaScript, HTML, CSS

## Backend Integration
The frontend consumes REST APIs exposed by the Spring Boot backend.
